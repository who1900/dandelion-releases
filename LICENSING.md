# Dandelion licensing

Dandelion rc16 is distributed under the **Business Source License 1.1
(BUSL-1.1)** with the Additional Use Grant in [LICENSE](LICENSE).
It is source-available, not currently OSI open source.

## Free use and Enterprise

Production use is free for a solo developer or a project team of **1–3 people**
when the organization benefiting from that use also consists of **1–3 people**.
Commercial projects are included. Both limits apply: three users inside a
larger company still require an Enterprise commercial license.

The organization count includes working owners, employees and individual
contractors; entities under common control are counted together. For work on
behalf of a client, the client organization is the relevant organization.
Count people, not agents, devices, connections, records or database size.
Multiple deployments do not reset the limits.

Production use beyond either limit, or providing a competing commercial
product/service based on Dandelion, requires a separate commercial license.
Contact the maintainer through the
[distribution repository](https://github.com/who1900/dandelion-releases/issues)
for Enterprise terms; do not post confidential project information.

The standard BSL rights to non-production use, copying, modification and
redistribution remain in place. The Additional Use Grant is not a prohibition
on studying or forking the code. Dependencies retain their own licenses.

## Time and existing releases

The Change License is Apache-2.0, supplied in [LICENSE-APACHE](LICENSE-APACHE).
For rc16 the Change Date is November 9, 2030; the BSL's earlier-of rule also
applies. Each later release must identify its Licensed Work and Change Date.

rc16 changes licensing and the release identifier, not memory behavior, schema
or the MCP interface. Existing memory directories, originals and history remain
usable. There is no new telemetry, license server or runtime feature gate.

Earlier MIT publications are historical releases. This change does not claim to
revoke rights already granted for copies of those releases. Current installation
instructions select rc16. The current licensing policy supersedes earlier
descriptions of the current product as MIT/open source.

This page explains the policy; the LICENSE text governs. The three-person grant
is project-specific wording and has not been independently reviewed by counsel.
